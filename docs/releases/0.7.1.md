# Tracebook 0.7.1

The default minimizer reduces the 15,739-event historical Flash FIFO trace to
the same four events in 19 candidate runs. Version 0.7.0 exhausted its default
100-run budget with 151 events left. With a 200-run allowance it reached the
four-event proof in 193 runs.

| Case | 0.7.0 runs to finish | 0.7.1 runs to finish | Reduced events |
| --- | ---: | ---: | ---: |
| Flash historical workload | 193 | 19 | 4 |
| Seed 42 historical partial fill | 16 | 8 | 4 |
| Seed 42 injected replacement fault | 16 | 12 | 5 |

All three reductions preserve the original proof bytes. In the Flash case,
the affected Rust engine fills maker 185199 before 146075. Removing any one
event eliminates the failure. The fixed engine passes the four-event proof.

For a mismatch in a trade's buy or sell order ID, the minimizer tries the
disputed orders and their direct counterparties first. The candidate must
reproduce the same pair of IDs on the triggering event for this shortcut to
be accepted. New minimization reports include the configured `max_runs`.
Readers of older reports can continue to use `runs` and `budget_exhausted`.

## Run the proof

Use Python 3.10–3.13, rustup with toolchain 1.88.0, a native C toolchain,
and access to the pinned Cargo dependencies. In an environment containing
`tracebook-sim` 0.5.x, remove that legacy package before installing either
0.7.1 distribution.

```bash
python -m pip uninstall -y tracebook-sim
```

In a fresh environment, install the conformance wheel and run the command
from an empty directory. It writes the verified four events to `fifo-proof.jsonl`.

```bash
python -m pip install "tracebook-conformance==0.7.1"
tracebook-conformance fifo-proof
```

For the simulator and workbench commands, install the matching facade.

```bash
python -m pip install "tracebook-sim==0.7.1"
```
