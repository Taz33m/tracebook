# Tracebook 0.7.2

A minimized trade order-ID mismatch now preserves the original triggering
event occurrence, buy or sell ID field, and reference and candidate order IDs
throughout reduction. A fill can move within the event's trade list as earlier
fills disappear. [PR #95](https://github.com/Taz33m/tracebook/pull/95)

The new 21-event regression originally diverges when order 21 fills sell maker
16 ahead of 15. The default minimizer preserves that mismatch in eight events
after 48 of 100 runs. Removing any one event loses the original mismatch.
The fixed Rust engine passes the full and reduced traces.

The three existing FIFO proofs have the same JSONL bytes and take 19, 8, and
12 candidate runs. Qualification IDs record the 0.7.2 reference-engine version.

## Run the proof

Use Python 3.10–3.13, rustup with toolchain 1.88.0, a native C toolchain,
and access to the pinned Cargo dependencies. When an environment contains
the legacy `tracebook-sim` 0.5.x package, uninstall it first.

```bash
python -m pip uninstall -y tracebook-sim
```

Install the conformance package in a fresh environment and run the proof from
an empty directory. It writes the verified four events to `fifo-proof.jsonl`.

```bash
python -m pip install "tracebook-conformance==0.7.2"
tracebook-conformance fifo-proof
```

For simulation and workbench commands, install the matching facade.

```bash
python -m pip install "tracebook-sim==0.7.2"
```
